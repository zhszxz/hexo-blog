# 一、条件语句

条件语句是各语言共通的语法，Python 的差异在于**用缩进定块**、**没有 switch**（3.10 起用 `match` 替代）、以及**条件表达式更简洁**。

### 1.1 缩进定块

Python 没有大括号，靠**缩进**划分代码块，同一代码块缩进必须一致（PEP 8 建议 4 个空格）：

```python
score = 688
if score > 680:
    print("恭喜你进入清华学习")   # 这两行同属 if 块
    print("即将步入精彩的大学生活")
print("--------------------")      # 这行缩进退回，不属于 if
```

> 缩进既是语法又是风格：混用空格和 Tab 会直接报 `IndentationError`，编辑器里请统一设置「Tab 展开为 4 个空格」。

### 1.2 单分支 / 双分支 / 多分支

```python
# 单分支
if score > 680:
    print("优秀")

# 双分支
year = int(input("请输入年份:"))
if year % 4 == 0 and year % 100 != 0 or year % 400 == 0:
    print(f"{year}是闰年")
else:
    print(f"{year}是平年")

# 多分支：elif 可以有任意多个，只执行第一个为真的分支
num = int(input("请输入整数:"))
if num > 0:
    print(f"{num}是正数")
elif num < 0:
    print(f"{num}是负数")
else:
    print(f"{num}是0")
```

`elif` 即「else if」的缩写。多分支一旦命中，后续分支不再判断。

### 1.3 三元表达式

Python 的三元表达式语法为 `值1 if 条件 else 值2`（注意顺序和 C 系语言不同）：

```python
age = 20
msg = "成年" if age >= 18 else "未成年"
print(msg)

# 嵌套（可读性差，慎用）
score = 88
level = "优" if score >= 90 else ("良" if score >= 80 else "及格")
```

### 1.4 真值判断

`if` 后面跟的可以是任意对象，Python 会把它转成布尔值判断。**假值**只有 8 个：`False`、`None`、`0`、`0.0`、`""`、`[]`、`()`、`{}`、`set()`（其中数值类的 0 和 0.0 可视为一类），其余都为真。所以常见的 `if x:` 写法：

```python
if lst:        # 等价于 if len(lst) > 0
    ...
if not s:      # 空字符串
    ...
```

### 1.5 match 结构化模式匹配（3.10+）

`match...case` 是 Python 3.10 引入的新语法，**不是传统 switch**，而是一种强大的「结构化模式匹配」。它不仅能按值匹配，还能按结构解包、绑定变量、加守卫条件。

基础用法（出自练习代码 `chapter02/06.match模式匹配.py`）：

```python
day = input("请输入星期数(1-7):")
match day:
    case "1":
        print("周一:工作会议日")
    case "2":
        print("周二:学习培训日")
    case "6" | "7":          # 用 | 匹配多个值
        print("周末:休息日")
    case _:                    # _ 通配符，匹配任意值（类似 default）
        print("输入有误")
```

带**守卫条件**（`if` 附加判断）：

```python
n1 = float(input("请输入操作数1:"))
n2 = float(input("请输入操作数2:"))
oper = input("请输入运算符:")
match oper:
    case "+":
        print(f"{n1} + {n2} = {n1 + n2}")
    case "/" if n2 != 0:        # 命中 "/" 且 n2 不为 0 才执行
        print(f"{n1} / {n2} = {n1 / n2}")
    case "/":
        print("除数不能为 0")
    case _:
        print("非法的操作!")
```

**结构化匹配**是 match 的精华——直接按形状解包数据（这是普通 if-elif 做不到的）：

```python
# 匹配序列并解包
def handle(point):
    match point:
        case [x, y]:                     # 匹配长度为 2 的列表，绑定 x、y
            print(f"二维坐标 ({x}, {y})")
        case [x, y, z]:
            print(f"三维坐标 ({x}, {y}, {z})")
        case (0, 0):
            print("原点")
        case _:
            print("未知格式")

# 匹配字典结构
def parse(config):
    match config:
        case {"type": "db", "host": host}:
            print(f"数据库地址: {host}")
        case {"type": "cache"}:
            print("缓存配置")
        case _:
            print("其他配置")

# 配合类型模式与 as 绑定
match value:
    case int() | float():
        print("是数字")
    case str(s) if len(s) > 3:
        print(f"长字符串: {s}")
    case str(s):
        print(f"短字符串: {s}")
```

> 小结：简单「值相等」判断用 `if-elif` 足够；一旦要「按数据结构形状」分派（如处理不同格式的 API 返回、命令行参数、JSON 结构），`match` 比一堆 if-elif 更清晰、更少 bug。

# 二、循环

Python 只有 `while` 和 `for` 两种循环，没有 C 系语言的 `do-while` 和 `for(;;)`。

### 2.1 while 循环

```python
i = 0
while i < 10:
    print("人生苦短,我用python")
    i += 1
```

- `while True` + `break` 是「无限循环直到满足条件退出」的惯用写法，适合猜数字、菜单、事件循环等场景：

```python
import random
random_number = random.randint(1, 100)
while True:
    n = int(input("猜数字:"))
    if n == random_number:
        print("猜中了!")
        break
    print("猜大了" if n > random_number else "猜小了")
```

### 2.2 for 循环（遍历可迭代对象）

Python 的 `for` 是「**遍历可迭代对象**」的语法，不依赖索引。字符串、列表、元组、字典、集合、range、文件等都能直接遍历：

```python
content = "hello"
for s in content:
    print(s)          # 逐个打印字符（Python 无字符类型，长度 1 仍是字符串）

for n in [1, 2, 3]:
    print(n)
```

想同时拿到索引和值，用 `enumerate()`：

```python
fruits = ["apple", "banana", "cherry"]
for i, fruit in enumerate(fruits):
    print(i, fruit)        # 0 apple / 1 banana / 2 cherry
```

想并行遍历多个序列，用 `zip()`：

```python
names = ["a", "b", "c"]
scores = [90, 80, 70]
for name, score in zip(names, scores):
    print(name, score)
```

### 2.3 range()

`range(start, stop, step)` 生成一个整数序列，**左闭右开**（含 start 不含 stop），步长可为负：

```python
print(list(range(5)))          # [0, 1, 2, 3, 4]，省略 start 默认 0
print(list(range(2, 6)))       # [2, 3, 4, 5]
print(list(range(1, 101, 2)))  # 1 到 100 的奇数
print(list(range(10, 0, -1)))  # 10 到 1 的降序

# 累加 1~100 的奇数
total = sum(range(1, 101, 2))
print(total)
```

> `range` 本身是惰性对象，`range(10**9)` 不会真的占 10 亿个元素的内存，遍历时才按需生成。

### 2.4 break / continue / pass

| 关键字 | 作用 |
| ------ | ---- |
| `break` | 立即跳出**当前层**循环 |
| `continue` | 跳过本次循环剩余代码，进入下一次迭代 |
| `pass` | 什么都不做的占位语句 |

```python
for i in range(10):
    if i == 3:
        continue      # 跳过 3
    if i == 8:
        break         # 到 8 就结束
    print(i)          # 打印 0 1 2 4 5 6 7
```

在嵌套循环中，`break` / `continue` 只作用于**最内层**循环（与 Java 的带标签 break 不同，Python 没有标签语法，需要跳出多层时通常用标志位或封装成函数 return）。

### 2.5 循环的 else 子句（Python 特有）

`while` / `for` 都可以带 `else`：**当循环正常结束（没有被 break 中断）时执行 else**。这是 Python 特有、也最容易被误读的语法：

```python
for n in range(2, 10):
    for x in range(2, n):
        if n % x == 0:
            break           # 被 break 中断，不执行 else
    else:
        print(f"{n} 是质数")  # 内层循环没 break，说明没有因数
```

经典场景是「查找」：找到了 break，没找到走 else 做兜底处理。

### 2.6 嵌套循环

```python
# 打印 m * n 的矩阵
for i in range(m):
    for j in range(n):
        print("*", end="")
    print()   # 每行结束后换行

# 九九乘法表
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j} * {i} = {j * i}\t", end="")
    print()
```

# 三、推导式（Python 特有重点）

推导式（Comprehension）是 Python 从集合论借来的语法，用一行表达式生成列表、字典、集合。它比手写 for 循环更简洁、执行更快，是「Pythonic」的标志之一。

### 3.1 列表推导式

语法：`[表达式 for 变量 in 可迭代对象 if 条件]`

```python
# 普通循环写法
squares = []
for x in range(10):
    squares.append(x ** 2)

# 推导式写法
squares = [x ** 2 for x in range(10)]
print(squares)   # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

# 带条件过滤
evens = [x for x in range(20) if x % 2 == 0]

# 表达式里可以做运算、调用函数
words = ["hello", "world"]
upper = [w.upper() for w in words]   # ['HELLO', 'WORLD']

# 带 if-else 的（注意位置不同：条件写在表达式里用三元，过滤写在后面用 if）
labels = ["偶数" if x % 2 == 0 else "奇数" for x in range(5)]
# ['偶数', '奇数', '偶数', '奇数', '偶数']
```

**嵌套推导式**（对应双层循环，等价于先外层后内层）：

```python
# 展平二维列表
matrix = [[1, 2], [3, 4], [5, 6]]
flat = [x for row in matrix for x in row]
print(flat)   # [1, 2, 3, 4, 5, 6]

# 所有 (x, y) 组合
pairs = [(x, y) for x in range(2) for y in range(2)]
# [(0, 0), (0, 1), (1, 0), (1, 1)]
```

> 可读性提醒：推导式写 1~2 层最合适，超过 3 层嵌套请改回普通循环，否则反而更难维护。

### 3.2 字典推导式

语法：`{键表达式: 值表达式 for ... in ... if ...}`

```python
# 键值互换
d = {"a": 1, "b": 2}
flipped = {v: k for k, v in d.items()}
print(flipped)   # {1: 'a', 2: 'b'}

# 平方表
squares = {x: x ** 2 for x in range(5)}
print(squares)   # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}
```

### 3.3 集合推导式

语法：`{表达式 for ... in ... if ...}`（用花括号但无冒号）

```python
# 去重并平方
nums = [1, 1, 2, 3, 3]
sq = {x ** 2 for x in nums}
print(sq)   # {1, 4, 9}
```

### 3.4 生成器表达式

把列表推导式的外层 `[]` 换成 `()`，得到**生成器表达式**。它**惰性求值**，不一次性生成全部元素，内存占用极低，适合大数据量：

```python
# 列表推导式：一次性生成 1 亿个元素，内存爆炸
# squares = [x ** 2 for x in range(10 ** 8)]

# 生成器表达式：不占内存，用多少取多少
squares = (x ** 2 for x in range(10 ** 8))
print(next(squares))   # 0
print(next(squares))   # 1
```

生成器的详细原理（`yield`、迭代协议）会在第 7 篇《高级语法》展开。

### 3.5 海象运算符在推导式中的应用

海象 `:=` 可把中间结果绑定到变量，避免在推导式里重复计算：

```python
# 传统写法：f(x) 被算了两次
result = [f(x) for x in data if f(x) > 0]

# 海象写法：只算一次
result = [y for x in data if (y := f(x)) > 0]
```

### 3.6 推导式 vs map/filter

推导式在多数场景下比 `map`/`filter` 更易读，是更「Pythonic」的选择：

```python
nums = [1, 2, 3, 4, 5]

# 函数式写法
evens = list(filter(lambda x: x % 2 == 0, nums))
doubles = list(map(lambda x: x * 2, nums))

# 推导式写法（更直观）
evens = [x for x in nums if x % 2 == 0]
doubles = [x * 2 for x in nums]
```

# 小结

本篇覆盖了流程控制的全部语法，其中**最需要重点掌握的是**：

1. **缩进定块**是 Python 与 C 系语言最根本的语法差异。
2. **`match` 结构化匹配**是 3.10+ 处理「按形状分派」的利器，与普通 switch 不同。
3. **循环 `else`** 的语义（正常结束才执行）极易混淆，务必记牢。
4. **推导式**（列表/字典/集合/生成器）是 Python 独有的高效语法，是写出 Pythonic 代码的核心能力。
