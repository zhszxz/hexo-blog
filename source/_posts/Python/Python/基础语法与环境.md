# 一、Python 语言特性与环境

### 1.1 Python 是什么

Python 是一门**解释型、动态类型、强类型**的通用编程语言，由 Guido van Rossum 于 1991 年发布。它以「简洁、优雅、可读」著称，语法接近伪代码，是当前企业级开发中使用最广泛的语言之一，尤其在 AI、数据分析、Web 后端、自动化运维等领域几乎成为事实标准。

核心特性：

- **解释型**：代码逐行翻译执行，无需编译；开发调试快，但运行速度不如编译型语言（可用 C 扩展、JIT 如 PyPy 弥补）。
- **动态类型**：变量无需声明类型，运行时才确定，同一个变量可以先后绑定不同类型的对象。
- **强类型**：不同类型之间不会隐式转换，`"1" + 1` 会直接报错，必须显式转换（这点和 JS 相反）。
- **面向对象**：一切皆对象，函数、类、模块本身都是对象。
- **胶水语言**：可轻松调用 C/C++/Java 等语言的库，也常作为系统间的粘合层。
- **缩进定界**：用缩进（建议 4 个空格）划分代码块，不用大括号。

> 理解「解释型 + 动态类型 + 强类型」这三个词是面试高频考点：解释型对应执行方式，动态/强类型对应类型系统。

### 1.2 解释器与版本

Python 代码需要解释器运行。官方解释器叫 **CPython**（C 语言实现），此外还有 PyPy（JIT 加速）、Jython（跑在 JVM 上）、IronPython（跑在 .NET 上）等。日常说的「Python」默认指 CPython。

版本方面，Python 2 已于 2020 年停止维护，企业开发统一使用 **Python 3**。几个常用版本的语法分水岭值得记住：

| 版本 | 新增特性 |
| ---- | -------- |
| 3.6  | f-string、变量注解、`dict` 有序 |
| 3.8  | 海象运算符 `:=`、仅位置参数 `/` |
| 3.9  | 字典合并运算符 `\|`、`str.removeprefix/removesuffix` |
| 3.10 | `match` 结构化模式匹配、`\|` 类型联合写法 |
| 3.11 | 异常组、`except*`、更快的解释器 |
| 3.12 | `f-string` 支持嵌套引号、PEP 701 |
| 3.13 | 无 GIL 实验性选项、JIT 实验 |

查看当前版本：`python --version`。企业项目通常会在文档里写死支持的版本范围（如 `>=3.9`），因为不同版本语法可能不兼容。

### 1.3 虚拟环境与包管理（企业级必备）

直接在系统 Python 里装包会导致不同项目依赖冲突（项目 A 要 Django 3，项目 B 要 Django 5）。**虚拟环境**为每个项目隔离一套独立的解释器与第三方包，是项目隔离的标准做法。

```bash
# 创建虚拟环境（在项目目录下生成 .venv 文件夹）
python -m venv .venv

# 激活（Windows）
.venv\Scripts\activate
# 激活（macOS / Linux）
source .venv/bin/activate

# 安装 / 卸载 / 查看包
pip install requests
pip install requests==2.31.0          # 指定版本
pip install -r requirements.txt        # 按清单批量安装
pip uninstall requests
pip list                               # 查看已装包
pip freeze > requirements.txt          # 导出依赖清单
```

核心要点：

- 激活后，`python`、`pip` 指向的就是虚拟环境里的解释器。
- `requirements.txt` 是项目依赖清单，团队协作时靠它同步环境；更现代的方案是 `poetry` 或 `uv`，能锁住依赖版本并管理发布。
- 依赖写死在 `requirements.txt` 或用 `poetry.lock` 锁版本，才能保证「别人装出来的环境和开发时一致」——这是企业项目可复现性的关键。

# 二、变量与对象模型

### 2.1 变量是「标签」而不是「盒子」

Python 的变量本质是一个**指向对象的引用（名字）**。赋值 `a = 10` 并不是「把 10 放进 a 这个盒子」，而是「让名字 a 指向整数对象 10」。所以：

```python
a = [1, 2, 3]
b = a          # b 和 a 指向同一个列表对象
b.append(4)
print(a)       # [1, 2, 3, 4]  ← a 也变了，因为改的是同一个对象
```

这与 C/Java 等语言的「值语义/变量即盒子」直觉不同，是很多 Python 初学者的第一道坎。想判断两个名字是否指向同一对象，用 `id()` 或 `is`：

```python
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)   # True，值相等
print(a is b)   # False，不是同一个对象
print(id(a), id(b))   # 两个不同的内存地址
```

### 2.2 动态类型

同一个变量可以被反复绑定到不同类型的对象（出自练习代码 `chapter02/01.字面量变量.py`）：

```python
num = 1144.1
num = num + 1      # 现在是 float 1145.1
num = "ok"         # 现在是 str
num = True         # 现在是 bool
```

动态类型让代码灵活，但也会让错误延迟到运行时才暴露，所以企业项目越来越多地借助**类型注解 + 静态检查工具（mypy）**来提前发现问题（详见第 6 篇）。

多变量赋值与解包：

```python
base, increase = 20.7, 50      # 同时赋值
a, b = b, a                    # 一行交换两个变量（Python 特有，无需临时变量）
x, *rest = [1, 2, 3, 4]        # x=1, rest=[2,3,4]，* 解包
```

### 2.3 `is` 与 `==` 的区别

这是面试和 bug 高发区：

- `==` 比较**值**是否相等（会调用对象的 `__eq__` 方法）。
- `is` 比较**身份**，即两个名字是否指向同一个对象（等价于 `id(a) == id(b)`）。

```python
a = [1, 2]
b = [1, 2]
print(a == b)   # True
print(a is b)   # False

# 小整数和短字符串有「驻留」优化，所以下面会是 True，但不要依赖它
x = 256
y = 256
print(x is y)   # True（CPython 对 [-5, 256] 的小整数做了缓存）
```

**铁律**：判断 `None` 必须用 `is None` 而不是 `== None`，因为 `None` 是单例，`==` 可能被对象重写导致误判。同理用 `is True / is False` 也要谨慎，一般直接 `if x:` 判断真假即可。

### 2.4 可变对象与不可变对象

这是理解 Python 传参、拷贝、深浅拷贝的前提：

| 不可变（immutable） | 可变（mutable） |
| ------------------- | --------------- |
| `int`、`float`、`bool`、`str`、`tuple`、`frozenset`、`bytes` | `list`、`dict`、`set`、自定义类实例 |

- 不可变对象一旦创建就不能改，任何「修改」其实都是新建一个对象。例如 `s = "abc"; s += "d"` 会创建一个新字符串 `"abcd"` 再让 `s` 指向它。
- 可变对象可以在原对象上修改，所以多个引用共享同一个可变对象时要特别小心（回到 2.1 的列表例子）。

```python
a = (1, 2, 3)
# a[0] = 10   # TypeError: 'tuple' object does not support item assignment

s = "hello"
# s[0] = "H"  # TypeError: 'str' object does not support item assignment
```

### 2.5 内存管理简述

Python 用**引用计数**管理内存：一个对象被引用一次计数 +1，引用消失计数 -1，计数归 0 时被回收。可通过 `sys.getrefcount(x)` 查看引用计数。引用计数无法处理「循环引用」（两个对象互相引用），所以 CPython 还搭配了**垃圾回收器 gc** 专门清理循环引用。日常开发中多数情况无需手动干预内存。

# 三、注释、标识符与关键字

### 3.1 注释

```python
# 单行注释

# 多行说明通常用三引号字符串充当「文档字符串」（docstring），
# 严格说它不是注释，而是字符串对象，但常被当作注释用。
def add(a, b):
    """返回两个数的和。"""   # 这是 docstring，可通过 help(add) 查看
    return a + b
```

### 3.2 标识符命名（PEP 8）

- 由字母、数字、下划线组成，**不能以数字开头**，区分大小写。
- 命名约定（企业协作的基本素养）：
  - 变量、函数：小写下划线 `user_name`、`get_user()`（snake_case）。
  - 类：大驼峰 `UserService`（PascalCase）。
  - 常量：全大写下划线 `MAX_SIZE`。
  - 以单下划线开头 `_x`：约定「私有」，`from m import *` 时不会被导入。
  - 以双下划线开头结尾 `__init__`：魔法方法，不要自己定义这类名字。

### 3.3 关键字

Python 内置了约 35 个关键字（如 `if`、`for`、`def`、`class`、`import`、`lambda`、`yield` 等），不能作为标识符。查看全部：

```python
import keyword
print(keyword.kwlist)
print(keyword.iskeyword("for"))   # True
```

# 四、数据类型

### 4.1 内置类型总览

Python 内置了丰富的数据类型，按用途分：

| 分类 | 类型 | 说明 |
| ---- | ---- | ---- |
| 数值 | `int` / `float` / `complex` / `bool` | 整数、浮点数、复数、布尔 |
| 序列 | `str` / `list` / `tuple` / `range` / `bytes` | 有序、可索引、可切片 |
| 集合 | `set` / `frozenset` | 无序、不重复 |
| 映射 | `dict` | 键值对 |
| 空值 | `NoneType` | 只有一个值 `None` |

序列、集合、映射统称「数据容器」，第 3、4 篇会详细展开。

### 4.2 数值类型

```python
print(10 / 4)    # 2.5，/ 永远返回 float
print(10 // 4)   # 2，整除，向下取整
print(2 ** 10)   # 1024，幂运算

# int 无限精度，理论上可表示任意大的整数
big = 2 ** 100   # 1267650600228229401496703205376，不会溢出
```

Python 的 `int` 没有 32 位/64 位溢出问题，这一点在企业处理金额、大数字时很方便。

浮点数精度陷阱（来自 IEEE 754，几乎所有语言都有）：

```python
print(0.1 + 0.2)       # 0.30000000000000004，不是精确的 0.3
print(round(0.1 + 0.2, 2))   # 0.3

# 需要精确十进制运算时用 decimal
from decimal import Decimal
print(Decimal("0.1") + Decimal("0.2"))   # 0.3
```

> 金额类业务不要直接用 float 做精确比较和运算，用 `Decimal` 或整数（以「分」为单位存储）。

### 4.3 布尔 bool 与 None

`bool` 是 `int` 的子类，`True` 等价于 1，`False` 等价于 0（出自练习代码）：

```python
print(True + 1)     # 2
print(False - 1)    # -1
print(isinstance(True, int))   # True
```

`None` 是 `NoneType` 类型的唯一实例，表示「空值/无返回值」。函数没有 return 时默认返回 `None`。判断必须用 `is None`。

### 4.4 类型查看与转换

```python
print(type(10))            # <class 'int'>
print(type("hello"))       # <class 'str'>
print(isinstance(10, int)) # True，判断类型（更推荐，支持继承判断）

int("123")      # 123
float("3.14")   # 3.14
str(100)        # "100"
bool(0)         # False
```

`bool()` 的转换规则（「假值」清单，务必记住，第 2 篇会用到）：

> 以下对象在布尔上下文中都是 `False`：`False`、`None`、`0`、`0.0`、`""`、`[]`、`()`、`{}`、`set()`；其余都是 `True`。

```python
print(bool([]))      # False
print(bool([0]))     # True，注意：列表里有元素就是 True，即使元素是 0
print(bool("0"))     # True，非空字符串是 True
```

# 五、运算符

### 5.1 算术运算符

| 运算符 | 含义 | 示例 | 结果 |
| ------ | ---- | ---- | ---- |
| `+ - *` | 加减乘 | `10 * 4` | 40 |
| `/` | 除法（恒为 float） | `10 / 4` | 2.5 |
| `//` | 整除（向下取整） | `10 // 4` | 2 |
| `%` | 取余 | `10 % 4` | 2 |
| `**` | 幂 | `2 ** 10` | 1024 |

两个 Python 特有、其他语言易踩坑的点：

- **`/` 永远返回浮点数**：`10 / 4` 是 2.5，不是 2（Java 里整数相除会截断）。
- **`//` 是向下取整，不是向 0 取整**（负数时和 Java 不同）：

```python
print(10 // 4)     # 2
print(-10 // 4)    # -3，向下取整到 -3，而不是 -2
print(-10 % 4)     # 2，Python 取余结果符号与除数一致
```

### 5.2 赋值与海象运算符

```python
num = 85
num += 10      # 复合赋值：num = num + 10
num //= 10     # 也支持 //=、%=、**= 等
```

海象运算符 `:=`（Python 3.8+）可以在表达式中一边赋值一边使用，避免重复计算：

```python
# 传统写法：要写两遍 len
data = [1, 2, 3]
n = len(data)
if n > 2:
    print(n)

# 海象写法：表达式里赋值并取值
if (n := len(data)) > 2:
    print(n)
```

它特别适合 while 循环里读取输入、推导式里复用中间结果等场景（第 2 篇会再举例）。

### 5.3 比较运算符与链式比较

```python
print(100 == 100)    # True
print(100 != 100)    # False
```

Python 支持**链式比较**，写法更接近数学：

```python
num = 15
print(10 <= num <= 20)    # True，等价于 10 <= num and num <= 20
print(10 <= num < 15)     # False
```

### 5.4 逻辑运算符与短路求值

Python 的逻辑运算符直接用英文单词 `and` / `or` / `not`（不是 `&&`、`||`、`!`），并且**返回参与运算的操作数本身**（这一点和 C/Java 返回布尔值不同）：

```python
print(True and False)    # False
print(1 and 2)           # 2  ← 短路：and 左侧为真时返回右侧值
print(0 and 2)           # 0  ← 左侧为假，直接返回左侧
print(0 or "hello")      # "hello"  ← or 左侧为假时返回右侧
print(1 or "hello")      # 1   ← 左侧为真，直接返回左侧
print(not True)          # False
```

利用短路特性可以写出简洁的默认值写法：

```python
name = input("输入姓名:") or "匿名用户"   # 输入为空字符串时用默认值
```

`and` / `or` 的优先级：`not > and > or`。写复杂条件时建议加括号提高可读性。

### 5.5 位运算符（简述）

`&`（按位与）、`|`（按位或）、`^`（按位异或）、`~`（按位取反）、`<<`（左移）、`>>`（右移）。用于底层、权限位、状态位等场景：

```python
print(0b1100 & 0b1010)   # 0b1000 = 8
print(1 << 10)           # 1024，左移相当于乘 2 的幂
print(5 ^ 5)             # 0，异或自身为 0
```

### 5.6 成员运算与身份运算

```python
print("a" in "abc")         # True，成员判断
print(2 not in [1, 2, 3])   # False

a = [1, 2]
b = a
print(a is b)      # True，身份判断
print(a is not b)  # False
```

### 5.7 运算符优先级（从高到低）

`**` → `+x/-x/~x`（一元）→ `* / // %` → `+ -` → `<< >>` → `&` → `^` → `|` → 比较/成员/身份 → `not` → `and` → `or` → 赋值/海象。

记不住就用括号，括号永远最清晰。

# 六、输入输出与格式化

### 6.1 输出 print()

```python
print("a", "b", "c")        # 默认以空格分隔
print("a", "b", sep="-")    # 自定义分隔符
print("hello", end="")      # 默认结尾换行 \n，改成空则不再换行
print("x", end=" -> ")
```

`print()` 的关键参数：`sep`（分隔符，默认空格）、`end`（结尾，默认 `\n`）、`file`（输出到文件对象，默认 stdout）。打印九九乘法表时常用 `end=""` 控制不换行。

### 6.2 输入 input()

```python
password = input("请输入密码:")   # 无论键入什么，返回的一定是 str
jine = input("请输入取款金额:")
print(f"账户余额:{10000 - int(jine)}")   # 需要手动 int() 转换
```

**要点**：`input()` 恒返回字符串，参与运算前必须 `int()`/`float()` 转换，否则 `"100" - 1` 会报 TypeError。

### 6.3 三种字符串格式化

Python 有 `%`、`str.format()`、f-string 三种格式化方式，如今**优先用 f-string**（3.6+，最简洁高效）。

```python
name, age, pro = "张三", 24, "学生"

# 方式一：% 占位符（老式，仍常见于旧代码）
msg = "我是%s，今年%d岁，是%s" % (name, age, pro)

# 方式二：str.format()
msg = "我是{}，今年{}岁，是{}".format(name, age, pro)
msg = "我是{0}，今年{1}岁，是{2}".format(name, age, pro)  # 可用索引复用

# 方式三：f-string（推荐）
msg = f"我是{name}，今年{age}岁，是{pro}"
```

`%` 占位符速查：`%s`（字符串）、`%d`（整数）、`%f`（浮点）、`%.2f`（保留两位小数）、`%x`（十六进制）。

### 6.4 f-string 进阶（Python 特有重点）

f-string 花括号内可以放任意**表达式**，还能带**格式说明符**：

```python
name = "张三"
score = 95.678
price = 1234567.89

# 大括号内写表达式、调用函数
print(f"{name.upper()} 考了 {score} 分")
print(f"3 + 5 = {3 + 5}")

# 宽度与对齐：{:宽度} 默认右对齐，< 左对齐，^ 居中，可用字符填充
print(f"{'a':>5}|")      # '    a|'  右对齐占 5 位
print(f"{'a':<5}|")      # 'a    |'  左对齐
print(f"{'a':^5}|")      # '  a  |'  居中
print(f"{'a':*^5}")      # '**a**'   用 * 填充

# 精度：保留小数位
print(f"{score:.2f}")    # 95.68
print(f"{score:.0f}")    # 96（四舍五入）

# 数值格式：千分位、进制、百分比
print(f"{price:,.2f}")   # 1,234,567.89
print(f"{255:#x}")       # 0xff
print(f"{255:b}")        # 11111111（二进制）
print(f"{0.85:.1%}")     # 85.0%

# 自文档化（3.8+）：= 会同时打印表达式和值，调试利器
x = 10
print(f"{x = }")         # x = 10
print(f"{x + 5 = }")     # x + 5 = 15

# 格式化日期（配合 datetime）
import datetime
now = datetime.datetime.now()
print(f"{now:%Y-%m-%d %H:%M:%S}")
```

### 6.5 repr() 与 str()

- `str(obj)` 面向用户，返回可读的字符串。
- `repr(obj)` 面向开发者，返回尽量可还原的表示，调试时更有用。

```python
s = "hi"
print(str(s))      # hi
print(repr(s))     # 'hi'（带引号，能看出是字符串）
```

`print()` 内部调用的是 `str()`，而 f-string 里 `{x!r}` 可以输出 repr 形式。
