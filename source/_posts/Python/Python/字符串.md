# 一、字符串的定义与不可变性

字符串 `str` 是 Python 中最常用的内置类型之一，本质上是一个**不可变、有序、可迭代的字符序列**。企业开发中大量的数据清洗、日志处理、参数拼接、正则匹配都围绕字符串展开，因此它的 API 是必须烂熟于心的。

### 1.1 定义方式

```python
s1 = 'Hello'
s2 = "Python"        # 单引号、双引号完全等价，方便字符串里含引号
s3 = """第一行
第二行
第三行"""             # 三引号定义多行字符串（也可作 docstring）
s4 = "it's ok"       # 双引号里直接写单引号，无需转义
s5 = 'He said "hi"'  # 单引号里直接写双引号
```

### 1.2 转义字符

| 转义 | 含义 |
| ---- | ---- |
| `\n` | 换行 |
| `\t` | 制表符 |
| `\\` | 反斜杠本身 |
| `\'` / `\"` | 引号 |
| `\r` | 回车 |

```python
print("Hello\nWorld")      # 换行
print("a\tb")              # a	b
print('Let\'s go')         # Let's go
```

需要「关闭转义」时用**原始字符串**，前缀 `r`：

```python
path = r"C:\Users\new\tmp"   # 反斜杠不再被当作转义
print(path)                  # C:\Users\new\tmp
```

> 原始字符串常用于正则表达式和 Windows 路径（第 9 篇正则里会大量使用 `r"..."`）。

### 1.3 不可变性

字符串一旦创建，**内容不可修改**。任何「修改」操作都会返回一个**新字符串**，原字符串不变：

```python
s = "Hello"
# s[0] = "h"      # TypeError: 'str' object does not support item assignment

s2 = s.upper()     # 返回新字符串 "HELLO"
print(s)           # 原字符串仍是 "Hello"
```

理解不可变性有两点实际意义：

1. 频繁拼接字符串不要用 `+=`（每次都会创建新对象），应使用 `join`（见第六节）。
2. 字符串作为字典 key 或集合元素是安全的，因为它的哈希值不会变。

### 1.4 Python 没有「字符」类型

与 C/Java 不同，Python 没有单独的 `char` 类型，**长度为 1 的字符串仍然是字符串**：

```python
for ch in "abc":
    print(type(ch), ch)    # <class 'str'> a ...
```

# 二、索引与切片

字符串是**有序**序列，支持通过索引访问单个元素，通过切片取子串。

### 2.1 索引

```python
s = "Hello-Python"
print(s[0])     # 'H'，正向索引从 0 开始
print(s[5])     # '-'
print(s[-1])    # 'n'，负索引从 -1（最后一个）开始
print(s[-7])    # 'P'
print(len(s))   # 12
```

索引越界会抛 `IndexError`：

```python
# print(s[100])   # IndexError: string index out of range
```

### 2.2 切片 [start:stop:step]

切片语法 `s[start:stop:step]`，**左闭右开**（含 start，不含 stop），三个参数均可省略：

| 省略情况 | 含义 |
| -------- | ---- |
| 省略 start | 从头开始 |
| 省略 stop | 到末尾 |
| 省略 step | 步长默认 1 |

```python
s = "Hello-Python"
print(s[0:5])        # 'Hello'
print(s[:5])         # 'Hello'，省略 start
print(s[6:])         # 'Python'，省略 stop
print(s[:])          # 'Hello-Python'，整串拷贝
print(s[0:12:2])     # 'HloPto'，步长 2 隔一个取一个
print(s[::-1])       # 'nohtyP-olleH'，负步长反转（经典写法）
print(s[-1:-7:-1])   # 'nohtyP'，从后往前取
```

**切片越界不报错**（与索引不同），会自动截到边界：

```python
print(s[0:100])      # 'Hello-Python'，不会报错
print(s[5:100])      # '-Python'
```

> 记忆要点：**索引越界报错，切片越界不报错**。反转字符串最快写法是 `s[::-1]`。

# 三、编码：str 与 bytes

编码是 Python 字符串最容易让初学者困惑、也最贴近实际（读写文件、网络传输）的话题。

### 3.1 核心概念

- **str**：内存中的字符串，是**Unicode 字符**的序列，与具体编码无关。
- **bytes**：二进制字节串，是**字节**的序列，是实际存储/传输的形态。
- 两者通过 `encode()`（str → bytes）和 `decode()`（bytes → str）互相转换，必须指定编码，**最常用 UTF-8**。

```python
s = "你好"
b = s.encode("utf-8")    # str -> bytes
print(b)                 # b'\xe4\xbd\xa0\xe5\xa5\xbd'
print(type(b))           # <class 'bytes'>

s2 = b.decode("utf-8")   # bytes -> str
print(s2)                # '你好'
```

### 3.2 为什么是 UTF-8

UTF-8 是可变长编码：ASCII 字符占 1 字节，中文占 3 字节。它是互联网的默认编码，跨平台、跨语言兼容性最好。乱码的根源几乎都是「编码与解码使用的编码不一致」：

```python
s = "你好"
b = s.encode("gbk")          # 用 GBK 编码
# print(b.decode("utf-8"))   # UnicodeDecodeError，用错编码解码
print(b.decode("gbk"))       # 正确
```

### 3.3 字符与码点

每个 Unicode 字符都有一个唯一码点（整数），用 `ord()` 查码点、`chr()` 由码点还原字符：

```python
print(ord("A"))     # 65
print(ord("你"))    # 20320
print(chr(65))      # 'A'
print(chr(20320))   # '你'
print(hex(ord("你")))   # 0x4f60
```

### 3.4 实践要点

- 读写文件时显式指定 `encoding="utf-8"`，避免依赖系统默认编码（Windows 默认可能不是 UTF-8）。
- 字节串前缀 `b`：`b"abc"` 是 bytes，`"abc"` 是 str，两者不能直接混用（如 `"a" + b"b"` 会报错）。
- 判断变量是字符串还是字节串：`isinstance(x, str)` / `isinstance(x, bytes)`。

# 四、常用方法速查（分类大全）

字符串方法有几十个，下面按用途分类整理，这是本篇的核心速查表。**方法都返回新字符串，不修改原字符串**（不可变性）。

### 4.1 判断类（返回 bool）

| 方法 | 作用 |
| ---- | ---- |
| `startswith(prefix)` | 是否以某前缀开头 |
| `endswith(suffix)` | 是否以某后缀结尾 |
| `isalpha()` | 是否全为字母 |
| `isdigit()` | 是否全为数字（只认 0-9） |
| `isnumeric()` | 是否全为数字（含中文数字、分数等，范围更广） |
| `isalnum()` | 是否全为字母或数字 |
| `isspace()` | 是否全为空白字符 |
| `isupper()` / `islower()` | 是否全为大写 / 小写 |
| `istitle()` | 是否每个单词首字母大写 |

```python
s = "Hello_World"
print(s.startswith("Hello"))   # True
print(s.endswith("World"))     # True
print("abc".isalpha())         # True
print("123".isdigit())         # True
print("壹".isnumeric())        # True（isdigit 则为 False）
```

### 4.2 查找类

| 方法 | 作用 | 找不到时 |
| ---- | ---- | -------- |
| `find(sub)` | 返回子串第一次出现的索引 | 返回 -1 |
| `rfind(sub)` | 从右往左找，返回索引 | 返回 -1 |
| `index(sub)` | 同 find | 抛 ValueError |
| `count(sub)` | 统计子串出现次数 | 返回 0 |

```python
s = "Hello_World_Hello"
print(s.find("_"))     # 5
print(s.rfind("_"))    # 11
print(s.count("o"))    # 3
print(s.count("Hello"))# 2
```

用 `in` 判断是否包含子串（最常用、最直观）：

```python
print("Hello" in s)    # True
print("x" not in s)    # True
```

### 4.3 大小写转换

| 方法 | 作用 |
| ---- | ---- |
| `upper()` / `lower()` | 转大写 / 小写 |
| `swapcase()` | 大小写互换 |
| `title()` | 每个单词首字母大写 |
| `capitalize()` | 整个字符串首字母大写，其余小写 |
| `casefold()` | 转小写（比 lower 更激进，适合大小写无关比较） |

```python
s = "hello world"
print(s.upper())       # 'HELLO WORLD'
print(s.title())       # 'Hello World'
print(s.capitalize())  # 'Hello world'

# 大小写无关比较推荐 casefold（能正确处理 ß 等特殊字符）
print("Straße".lower() == "STRASSE".lower())       # False
print("Straße".casefold() == "STRASSE".casefold()) # True
```

### 4.4 修剪与对齐

| 方法 | 作用 |
| ---- | ---- |
| `strip(chars)` | 去除两端指定字符（默认空白） |
| `lstrip(chars)` / `rstrip(chars)` | 只去左端 / 右端 |
| `ljust(w, fill)` / `rjust(w, fill)` | 左对齐 / 右对齐，宽度不足用 fill 填充 |
| `center(w, fill)` | 居中 |
| `zfill(w)` | 左侧补 0 到指定宽度 |

```python
s = "  hello  \n"
print(s.strip())          # 'hello'，去两端空白
print("xxhelloxx".strip("x"))   # 'hello'，去指定字符

print("42".zfill(5))      # '00042'，数字补零常用
print("hi".ljust(5, "*")) # 'hi***'
print("hi".center(5))     # '  hi '
```

### 4.5 分割与拼接

| 方法 | 作用 |
| ---- | ---- |
| `split(sep)` | 按分隔符切分成列表 |
| `rsplit(sep, n)` | 从右往左切分，可限制次数 |
| `splitlines()` | 按行切分 |
| `partition(sep)` | 切成 (前, 分隔符, 后) 三元组，只切第一次 |
| `rpartition(sep)` | 从右往左，只切最后一次 |
| `join(iterable)` | 用字符串连接可迭代对象中的元素 |

```python
s = "apple,banana,cherry"
print(s.split(","))            # ['apple', 'banana', 'cherry']
print(s.split(",", 1))         # ['apple', 'banana,cherry']，限制切分次数

# partition 适合「取第一段」的场景，比 split 更稳（分隔符不存在也不报错）
print(s.partition(","))        # ('apple', ',', 'banana,cherry')

# join 是拼接的标准做法
words = ["a", "b", "c"]
print("-".join(words))         # 'a-b-c'
print(",".join(["1", "2"]))    # '1,2'
```

> `join` 要求可迭代对象里的元素都是字符串，否则报错：`"-".join([1, 2])` 会 TypeError，需先 `"-".join(map(str, [1, 2]))`。

### 4.6 替换

| 方法 | 作用 |
| ---- | ---- |
| `replace(old, new, count)` | 替换子串，count 限制次数 |
| `translate(table)` | 按映射表批量替换（配 maketrans） |
| `maketrans(a, b)` | 生成字符映射表 |
| `expandtabs(n)` | 把 \t 展开为空格 |

```python
s = "hello world"
print(s.replace("o", "0"))        # 'hell0 w0rld'
print(s.replace("o", "0", 1))     # 'hell0 world'，只替换第一个

# translate 做批量字符映射（如加密、清洗）
table = str.maketrans("aeiou", "12345")
print("hello".translate(table))   # 'h2ll4'
```

### 4.7 格式化与编码

| 方法 | 作用 |
| ---- | ---- |
| `format(*args)` | 占位符格式化（老式） |
| `encode(encoding)` | str → bytes |

`format` 已被 f-string 取代（详见第五节和第一篇 6.4 节），此处略过。

# 五、字符串格式化（f-string 进阶）

三种格式化方式（`%`、`str.format()`、f-string）已在第一篇介绍，这里补充 format 规格的细节速查。f-string 的格式说明符与 `str.format()` 完全一致，格式为 `{[表达式]:[格式说明]}`。

### 5.1 对齐、填充、宽度

```python
#  格式：{值:填充字符 对齐符 宽度}
print(f"{'x':>6}")     # '     x'  右对齐（默认）
print(f"{'x':<6}")     # 'x     '  左对齐
print(f"{'x':^6}")     # '   x  '  居中
print(f"{'x':-^6}")    # '--x---'  用 - 填充并居中
print(f"{'x':=6}")     # 数字用 = 让符号靠左（见下）
```

对齐符速记：`<` 左、`>` 右、`^` 中、`=`（仅数字，填充在符号和数字之间）。

### 5.2 精度、进制、千分位

```python
pi = 3.1415926
print(f"{pi:.2f}")     # 3.14   保留两位小数
print(f"{pi:.3e}")     # 3.142e+00  科学计数
print(f"{0.852:.1%}")  # 85.2%  百分比
print(f"{255:#x}")     # 0xff   十六进制（# 带前缀）
print(f"{255:b}")      # 11111111  二进制
print(f"{255:o}")      # 377    八进制
print(f"{1234567:,}")  # 1,234,567  千分位

# 整数 d、字符串 s 也可以指定宽度
print(f"{42:04d}")     # 0042   补零到 4 位
```

### 5.3 其他技巧

```python
name = "张三"
print(f"{name:10}")    # 字符串默认左对齐，占 10 位
print(f"{name!r}")     # '张三'  用 repr 显示（带引号）
print(f"{name!s}")     # 张三   用 str 显示（默认）

# 3.8+ 自文档化调试
x = 42
print(f"{x=}")         # x=42

# 3.12+ 支持与外侧引号相同的嵌套引号
print(f"{'a' if x > 0 else 'b'}")  # a
```

# 六、拼接性能与最佳实践

### 6.1 `+` 拼接 vs `join`

`+` 每次拼接都会**创建一个新字符串**（不可变性导致），循环里用 `+=` 是 O(n²) 的灾难：

```python
# 反例：字符串循环拼接，每轮都复制一次
s = ""
for i in range(10000):
    s += str(i)          # 慢

# 正例：先收集到列表，最后 join 一次
parts = []
for i in range(10000):
    parts.append(str(i))
s = "".join(parts)       # 快
```

结论：**循环拼接字符串一律用 `join`**；少量固定拼接用 `+` 或 f-string 即可。

### 6.2 三种格式化怎么选

| 场景 | 推荐 |
| ---- | ---- |
| 日常拼接、带变量 | f-string（最简洁、最快） |
| 模板可配置、需复用 | `str.format()` |
| 兼容老代码 | `%` |

# 七、综合案例（摘自练习代码）

### 7.1 验证邮箱

```python
# 要求：包含且仅包含一个 '@'，且至少有一个 '.'
mail = input("请输入邮箱:")
if mail.count('@') == 1 and '.' in mail:
    print(f"{mail}是合法的邮箱")
else:
    print(f"{mail}是非法的邮箱")
```

### 7.2 字符串转大写再反转

```python
# 接收 10 个字符串，转大写并反转后存入列表
str_list = []
for i in range(10):
    str_list.append(input("请输入str:").upper()[::-1])  # 链式调用：upper 再反转

for s in str_list:
    print(s)
```

这个例子体现了 Python 字符串的「方法链式调用」：`input().upper()[::-1]` 一行完成输入 → 转大写 → 切片反转，是日常写代码的典型风格。

### 7.3 反转字符串 / 判断回文

```python
def is_palindrome(s):
    return s == s[::-1]     # 切片反转后与原串比较

print(is_palindrome("上海自来水来自海上"))   # True
```

# 小结

字符串是 Python 中 API 最丰富、使用频率最高的类型。核心要掌握：

1. **不可变性**：修改必返回新串，这决定了拼接用 `join` 而不是 `+=`。
2. **索引与切片**：`[start:stop:step]` 左闭右开、负索引、`[::-1]` 反转；索引越界报错、切片不报错。
3. **str 与 bytes 编码**：`encode`/`decode` 配 UTF-8，读写文件和网络传输必须显式指定编码。
4. **方法速查**：判断 / 查找 / 大小写 / 修剪对齐 / 分割拼接 / 替换六大类，`split`、`join`、`strip`、`replace`、`find`、`startswith` 是最高频的六个。
5. **f-string 格式规格**：对齐、填充、宽度、精度、进制、千分位，与 `str.format()` 通用。
