# 一、列表 list

列表是最常用的可变序列，**有序、可重复、有索引、可存任意类型**（甚至混合类型）。Python 的列表比 Java 的数组/ArrayList 灵活得多，是企业开发中的主力容器。

### 1.1 创建与访问

```python
s = [56, 78, 91, 2.718, 3.14, "Hello", True]   # 可混合类型
print(type(s))        # <class 'list'>
print(len(s))         # 7

print(s[0])           # 56，正向索引
print(s[-1])          # True，反向索引
```

列表是**可变**的，支持直接修改元素：

```python
s[0] = 100            # 修改
print(s)
del s[1]              # 删除指定索引元素
```

### 1.2 切片

列表切片语法与字符串完全一致 `s[start:stop:step]`，**返回一个新的列表**：

```python
s = ['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H', 'I', 'J']
print(s[0:5])          # ['A','B','C','D','E']
print(s[:5])           # 同上，省略 start
print(s[1:-2:2])       # ['B','D','F','H']，步长 2
print(s[::-1])         # 反转列表
```

切片是拷贝（浅拷贝），`s[:]` 常用来快速复制列表。

### 1.3 常用方法（速查表）

| 方法 | 作用 | 说明 |
| ---- | ---- | ---- |
| `append(x)` | 尾部追加 | 最常用，O(1) |
| `insert(i, x)` | 指定索引插入 | O(n) |
| `extend(iterable)` | 批量追加另一个序列 | 相当于 `+=` |
| `remove(x)` | 删除**第一个**匹配值 | 不存在抛 ValueError |
| `pop(i)` | 删除并返回索引元素 | 默认删最后一个 |
| `clear()` | 清空 | |
| `index(x)` | 查找索引 | 不存在抛 ValueError |
| `count(x)` | 统计出现次数 | |
| `sort()` | 原地排序 | |
| `reverse()` | 原地反转 | 区别于 `[::-1]`（返回新列表） |
| `copy()` | 浅拷贝 | 等价 `s[:]` |

```python
s = [56, 90, 88, 65, 90, 100]
s.append(108)         # 尾部追加
s.insert(2, 80)       # 索引 2 处插入
s.remove(90)          # 删除第一个 90
s.pop(1)              # 删除索引 1 并返回
s.sort()              # 升序
s.reverse()           # 反转
```

注意 `reverse()` 是原地反转，`s[::-1]` 是返回反转后的新列表，两者别混。

### 1.4 sort 与 sorted、key 参数

- `list.sort()`：**原地**排序，返回 None。
- `sorted(iterable)`：返回**新列表**，原数据不变，可对任意可迭代对象排序。

两者的 `key` 参数（指定排序依据函数）、`reverse` 参数（是否降序）用法一致：

```python
words = ["C++", "Python", "Go", "JavaScript", "Rust"]
words.sort(key=len, reverse=True)    # 按长度降序
print(words)

nums = [3, -1, 5, -8]
print(sorted(nums, key=abs))         # 按绝对值排序 [-1, 3, 5, -8]
```

`key` 接收一个函数，排序时对每个元素先调该函数再比较——这是 Python 排序最灵活、也最常用的特性。

### 1.5 列表推导式

```python
# 生成 [1,20] 的平方列表
squares = [i ** 2 for i in range(1, 21)]

# 提取偶数并平方
nums = [12, 32, 45, 77, 80, 92]
result = [i ** 2 for i in nums if i % 2 == 0]
```

详细语法见第 2 篇《流程控制与推导式》。

### 1.6 底层实现（面试考点）

列表底层是**动态数组**（连续内存）：

- 索引访问、尾部追加 `append` 是 **O(1)**。
- 中间插入/删除需要移动元素，是 **O(n)**。
- 查找某值 `in` 是 **O(n)**（需遍历）。
- 列表扩容时会预留额外空间（整体分配），因此 `append` 是**均摊** O(1)。

# 二、元组 tuple

元组是**不可变的序列**，一旦创建，元素不能增删改。适合存「不希望被修改」的数据。

### 2.1 定义与访问

```python
t1 = (80, 95, 78, 50, 75)
print(t1[0])      # 80
print(t1[-1])     # 75
print(t1[:3])     # (80, 95, 78)，切片返回新元组
# t1[0] = 100     # TypeError，不可修改
```

方法只有两个：`count()`（统计次数）、`index()`（查索引）。

### 2.2 单元素元组的坑

```python
t = (100)         # 括号只是普通括号，这是 int！
print(type(t))    # <class 'int'>

t = (100,)        # 必须加逗号才是元组
print(type(t))    # <class 'tuple'>
```

### 2.3 组包与解包（Python 特有重点）

```python
# 组包：多个值自动打包成元组（括号可省略）
t = 5, 7, 9, 1, 13
print(t)          # (5, 7, 9, 1, 13)

# 解包：把元组拆开赋给多个变量，数量必须一致
a, b, c, d, e = t
print(a, b)       # 5 7

# 用 * 收集未知数量的元素（返回 list）
first, *middle, last = t
print(first)      # 5
print(middle)     # [7, 9, 1]
print(last)       # 13

# 交换变量本质就是组包+解包
a, b = 10, 20
a, b = b, a       # a=20, b=10
```

解包是 Python 最优雅的特性之一，广泛用于函数多返回值、遍历 `dict.items()`、交换变量等场景。

### 2.4 元组的用途

- **函数多返回值**：`return area, length` 本质就是返回一个元组（见第 5 篇）。
- **不可变数据**：配置、常量集合，防止被误改。
- **作为字典 key**：元组不可变、可哈希，常做复合键（如 `dict[(1, 2)] = "坐标"`）。
- **命名元组 namedtuple**：给元组每个位置起名，可读性更好：

```python
from collections import namedtuple
Point = namedtuple("Point", ["x", "y"])
p = Point(10, 20)
print(p.x, p.y)     # 10 20，可以按名字访问，也有索引
```

# 三、集合 set

集合是**无序、可变、自动去重**的容器，基于哈希表实现，**成员判断是 O(1)**。

### 3.1 创建与空集合的坑

```python
s = {1, 2, 2, 3, 3}     # 自动去重
print(s)                # {1, 2, 3}

s = {}                  # 注意：这是空字典，不是集合！
print(type(s))          # <class 'dict'>
s = set()               # 空集合必须用 set()
print(type(s))          # <class 'set'>
```

### 3.2 常用方法

| 方法 | 作用 | 说明 |
| ---- | ---- | ---- |
| `add(x)` | 添加元素 | |
| `remove(x)` | 删除元素 | 不存在抛 KeyError |
| `discard(x)` | 删除元素 | 不存在不报错（更安全） |
| `pop()` | 随机删除并返回一个元素 | 无序，无「最后」概念 |
| `clear()` | 清空 | |

```python
s = {100, 200, 300}
s.add(400)         # {100,200,300,400}
s.remove(200)      # {100,300,400}
s.discard(999)     # 不报错
```

### 3.3 集合运算（去重/交集/并集/差集）

集合支持数学意义的集合运算，用运算符或方法两种写法：

| 运算 | 运算符 | 方法 |
| ---- | ------ | ---- |
| 交集 | `&` | `intersection()` |
| 并集 | `\|` | `union()` |
| 差集 | `-` | `difference()` |
| 对称差 | `^` | `symmetric_difference()` |

```python
s1 = {'A', 'B', 'C', 'D'}
s2 = {'C', 'D', 'E', 'F'}

print(s1 & s2)     # {'C', 'D'}  交集
print(s1 | s2)     # 并集
print(s1 - s2)     # {'A', 'B'}  差集（在 s1 不在 s2）
print(s1 ^ s2)     # {'A','B','E','F'}  对称差（各自独有的）
```

典型应用（摘自练习代码「选课统计」）：

```python
football = {"王林", "曾牛", "韩立"}
basketball = {"张铁", "王林", "韩立"}
# 同时选两门
both = football & basketball
# 选了足球没选篮球
only_football = football - basketball
```

### 3.4 frozenset 不可变集合

`frozenset` 是不可变的集合，可作为字典 key、集合元素：

```python
fs = frozenset([1, 2, 3])
d = {fs: "value"}    # 可哈希，能作 key
```

### 3.5 用途小结

- **去重**：`list(set(数据))` 快速去重（注意会丢失顺序）。
- **成员判断快**：`x in set` 是 O(1)，比 `x in list` 的 O(n) 快得多，适合大量判断。

# 四、字典 dict

字典存储**键值对（key-value）**，key 唯一。它是 Python 最核心的数据结构之一，企业开发中几乎无处不在（配置、缓存、JSON 解析、对象映射等）。

### 4.1 创建与访问

```python
d = {"韩立": 688, "李化元": 560, "紫灵": 670}
print(d["韩立"])         # 688，key 不存在会抛 KeyError

# key 必须是不可变类型（可哈希），list/set/dict 不能作 key
# d = {[1, 2]: "x"}     # TypeError: unhashable type: 'list'
```

### 4.2 增删改

```python
d = {"a": 1}
d["b"] = 2        # 添加（key 不存在）
d["a"] = 100      # 修改（key 已存在）
del d["a"]        # 删除
value = d.pop("b")# 删除并返回值
```

### 4.3 常用方法（速查表）

| 方法 | 作用 |
| ---- | ---- |
| `get(key, default)` | 取值，**key 不存在返回默认值（不报错）** |
| `setdefault(key, default)` | 有则取值，无则先写入默认值再返回 |
| `keys()` / `values()` / `items()` | 返回所有键 / 值 / 键值对视图 |
| `pop(key)` | 删除并返回值 |
| `popitem()` | 删除并返回最后一对（3.7+ 保序） |
| `update(dict)` | 合并另一个字典（覆盖） |
| `clear()` | 清空 |

```python
d = {"a": 1}
print(d.get("b"))          # None，不报错
print(d.get("b", 0))       # 0，指定默认值
print(d.setdefault("c", 3))# 3，写入并返回
print(d)                   # {'a': 1, 'c': 3}
```

**`get` vs 下标访问**：用 `d[key]` 时 key 不存在会抛 KeyError；用 `d.get(key)` 返回 None 或指定默认值。生产代码中读不保证存在的 key 一律用 `get`。

### 4.4 遍历（含解包）

```python
d = {"韩立": 688, "紫灵": 670}

for key in d:               # 默认遍历 key
    print(key, d[key])

for key, value in d.items():  # 最常用：items + 解包
    print(f"{key}: {value}")
```

`keys()`/`values()`/`items()` 返回的是**视图对象**，会实时反映字典变化，可迭代、可判断成员（`"x" in d` 判断的是 key 是否存在）。

### 4.5 合并与解包（3.9+）

```python
d1 = {"a": 1, "b": 2}
d2 = {"b": 3, "c": 4}

merged = d1 | d2              # 合并，后者覆盖前者 {'a':1,'b':3,'c':4}
d1 |= d2                      # 原地合并

merged2 = {**d1, **d2}        # 用 ** 解包合并（兼容 3.5+）
```

### 4.6 底层实现（面试考点）

字典底层是**哈希表**：

- 查找、插入、删除平均都是 **O(1)**。
- **key 必须可哈希（不可变）**：`int`/`str`/`tuple`/`frozenset` 可以，`list`/`dict`/`set` 不行。
- **3.7+ 字典保证插入顺序**（按插入顺序遍历），之前版本不保证。

### 4.7 综合案例：购物车系统

摘自练习代码 `chapter02/13.数据容器-dict.py`，用字典 + match 实现增删改查：

```python
shopping_cart = {}
while True:
    choice = input("请选择操作(1-5):")
    match choice:
        case "1":
            name = input("商品名称:")
            if name in shopping_cart:
                print("商品已存在")
                continue
            shopping_cart[name] = {"price": float(input("价格:")), "num": int(input("数量:"))}
        case "2":
            name = input("商品名称:")
            if name not in shopping_cart:
                print("商品不存在")
                continue
            shopping_cart[name] = {"price": float(input("价格:")), "num": int(input("数量:"))}
        case "3":
            name = input("商品名称:")
            del shopping_cart[name]
        case "4":
            for name, info in shopping_cart.items():
                print(f"商品:{name} 价格:{info['price']} 数量:{info['num']}")
        case "5":
            break
        case _:
            print("输入有误")
```

# 五、深浅拷贝（重点难点）

这是 Python 面试和 bug 高发区，核心要先理解「可变对象与引用」的关系（第 1 篇 2.4 节）。

### 5.1 赋值 vs 浅拷贝 vs 深拷贝

```python
import copy

a = [1, 2, [3, 4]]

b = a                 # ① 赋值：b 和 a 指向同一对象
c = a.copy()          # ② 浅拷贝：新列表，但内层可变对象仍共享
d = copy.deepcopy(a)  # ③ 深拷贝：连同内层对象一起复制

# 改内层可变对象
a[2].append(5)
print(b)   # [1, 2, [3, 4, 5]]  ← 赋值：跟着变
print(c)   # [1, 2, [3, 4, 5]]  ← 浅拷贝：内层共享，也跟着变
print(d)   # [1, 2, [3, 4]]     ← 深拷贝：完全独立，不变
```

记忆要点：

- **赋值 `=`**：多一个名字指向同一对象，改谁都一样。
- **浅拷贝**：新建外层容器，但**内层元素仍是原对象的引用**；内层有可变对象时仍会互相影响。
- **深拷贝**：递归复制所有层，得到完全独立的副本。

浅拷贝的实现方式：`a.copy()`、`a[:]`、`list(a)`、`copy.copy(a)`。

### 5.2 什么时候用

- 传参时不想影响原数据，且数据是「一层」的 → 浅拷贝够用。
- 数据嵌套多层可变对象、需要完全隔离 → 深拷贝。
- 深拷贝会递归复制，代价较大，能浅拷贝就浅拷贝。

# 六、collections 常用扩展

标准库 `collections` 提供了几个企业级高频使用的容器：

### 6.1 Counter（计数器）

统计元素出现次数，返回一个字典子类：

```python
from collections import Counter

words = ["a", "b", "a", "c", "a", "b"]
c = Counter(words)
print(c)                 # Counter({'a': 3, 'b': 2, 'c': 1})
print(c["a"])            # 3
print(c.most_common(2))  # [('a', 3), ('b', 2)]，出现最多的前 2 个
```

典型场景：统计词频、统计字符、TopK。

### 6.2 defaultdict（带默认值的字典）

访问不存在的 key 时自动创建默认值，省去手动初始化：

```python
from collections import defaultdict

# 按首字母分组
words = ["apple", "banana", "avocado", "cherry"]
groups = defaultdict(list)
for w in words:
    groups[w[0]].append(w)      # 不存在的 key 自动创建空 list
print(groups)                    # defaultdict(..., {'a': ['apple','avocado'], 'b':['banana'], 'c':['cherry']})
```

常用默认值：`defaultdict(list)`、`defaultdict(int)`、`defaultdict(set)`。

### 6.3 OrderedDict（有序字典）

3.7+ 普通字典已保证插入顺序，但 `OrderedDict` 额外支持「把某键移到末尾」等操作，且相等比较会考虑顺序：

```python
from collections import OrderedDict
od = OrderedDict()
od["a"] = 1
od["b"] = 2
od.move_to_end("a")   # 把 a 移到末尾
print(od)             # OrderedDict([('b', 2), ('a', 1)])
```

### 6.4 deque（双端队列）

两端都能高效插入删除（O(1)），比 list 在头部插入快得多：

```python
from collections import deque
q = deque([1, 2, 3])
q.append(4)           # 尾部加
q.appendleft(0)       # 头部加
print(q.pop())        # 4
print(q.popleft())    # 0
```

适合做队列（先进先出）、滑动窗口等场景。

### 6.5 namedtuple（命名元组）

见第 2.3 节，给元组字段命名，兼顾不可变与可读性。

# 七、解包 `*` 的广泛应用（串讲）

`*` 解包是贯穿各容器的通用语法，这里汇总一次：

```python
# 1. 合并列表
a, b = [1, 2], [3, 4]
merged = [*a, *b]        # [1, 2, 3, 4]

# 2. 合并集合 / 字典
s = {*set1, *set2}
d = {**d1, **d2}

# 3. 函数调用时展开参数
def f(x, y, z): ...
args = [1, 2, 3]
f(*args)                 # 等价 f(1, 2, 3)

# 4. 解包赋值（收集多余元素）
first, *rest = [1, 2, 3, 4]   # first=1, rest=[2,3,4]
```

# 小结

四种容器各有定位，选型速查：

| 容器 | 是否可变 | 是否有序 | 是否可重复 | 典型场景 |
| ---- | -------- | -------- | ---------- | -------- |
| list | 可变 | 有序 | 可重复 | 通用序列、需索引/切片/增删 |
| tuple | 不可变 | 有序 | 可重复 | 多返回值、常量、字典 key |
| set | 可变 | 无序 | 不重复 | 去重、集合运算、快速成员判断 |
| dict | 可变 | 有序(3.7+) | key 不重复 | 键值映射、配置、JSON 解析 |

本篇重点：list 的 `sort(key=)` 与推导式、tuple 的组包解包、set 的集合运算、dict 的 `get`/`items`/`|` 合并与哈希表原理，以及**深浅拷贝**（赋值/浅拷贝/深拷贝三者的区别是高频考点）。`collections` 里的 Counter、defaultdict、deque 是生产代码常客。
