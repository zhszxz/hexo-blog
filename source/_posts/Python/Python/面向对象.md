# 一、类与对象

面向对象（OOP）把数据和操作数据的方法封装成「类」。Python 的一切都是对象，类本身也是对象（是 `type` 的实例）。

### 1.1 定义类与创建对象

```python
class Car:
    pass

c1 = Car()               # 创建实例对象
```

Python 对象**支持动态添加属性**（非常灵活，但也容易写错拼写而不报错）：

```python
c1.color = "red"
c1.brand = "BMW"
print(c1.__dict__)       # {'color': 'red', 'brand': 'BMW'}
```

> 每个实例的属性实际存储在实例的 `__dict__` 字典里（除非用了 `__slots__`，见第八节）。

### 1.2 `__init__` 构造方法 与 self

`__init__` 在对象创建时**自动调用**，用于初始化属性。`self` 表示「当前实例对象」，不是关键字，只是约定俗成的名字（可以是任何名字，但全行业都用 self）：

```python
class Car:
    def __init__(self, color, brand, name, price):
        self.color = color      # 把参数绑定为实例属性
        self.brand = brand
        self.name = name
        self.price = price

c1 = Car("红色", "BMW", "X7", 800000)
print(c1.__dict__)      # {'color': '红色', 'brand': 'BMW', ...}
```

要点：

- `self` 是「谁调用方法，self 就是谁」，通过 `实例.方法()` 调用时 Python 自动把实例传给 self。
- `__init__` 与 `__new__` 的区别：`__new__` 负责「创建对象」（先执行），`__init__` 负责「初始化对象」（后执行），日常只写 `__init__`，`__new__` 用于单例等特殊场景（见第八节）。

### 1.3 实例方法

定义在类中的函数叫方法，第一个参数必须是 `self`：

```python
class Car:
    def __init__(self, color, brand, name, price):
        self.color, self.brand, self.name, self.price = color, brand, name, price

    def running(self):
        print(f"{self.brand} {self.name} 正在高速行驶中....")

    def total_cost(self, discount, rate=0.1):
        return self.price * discount + rate * self.price

c1 = Car("红色", "BMW", "X7", 800000)
c1.running()                    # BMW X7 正在高速行驶中....
print(c1.total_cost(0.9, 0.1))  # 800000.0
```

# 二、类属性与实例属性

- **实例属性**：属于某个具体实例，各实例独立（在 `__init__` 里用 `self.xxx` 定义）。
- **类属性**：属于类，所有实例**共享**（在类体里直接定义）。

```python
class Car:
    wheel = 4           # 类属性，所有车共享
    tax_rate = 0.1

    def __init__(self, color):
        self.color = color   # 实例属性

c1 = Car("白色")
print(c1.color)        # 白色（实例属性）
print(c1.wheel)        # 4（类属性）
print(Car.wheel)       # 4（通过类名访问）
```

**属性查找顺序**：实例属性 → 类属性 → 父类属性。通过实例访问类属性时，先看实例有没有同名属性，没有才去类里找。但**通过实例赋值**会新建实例属性（遮蔽类属性），不会改类属性：

```python
c1.wheel = 6           # 给 c1 新建了实例属性 wheel=6
print(c1.wheel)        # 6
print(Car.wheel)       # 4，类属性没变
```

# 三、三类方法

| 类型 | 装饰器 | 第一参数 | 访问对象 |
| ---- | ------ | -------- | -------- |
| 实例方法 | 无 | `self` | 实例 |
| 类方法 | `@classmethod` | `cls` | 类 |
| 静态方法 | `@staticmethod` | 无 | 都不访问 |

### 3.1 类方法 @classmethod

第一个参数是 `cls`（类本身），适合操作**类属性**、或作为「备选构造器」：

```python
class Car:
    count = 0
    def __init__(self):
        Car.count += 1

    @classmethod
    def get_count(cls):
        return cls.count

Car(); Car()
print(Car.get_count())   # 2，通过类名调用
```

### 3.2 静态方法 @staticmethod

不访问实例也不访问类，只是「归类存放的工具函数」，可用类名或实例调用：

```python
class MathTool:
    @staticmethod
    def add(a, b):
        return a + b

print(MathTool.add(3, 5))   # 8
```

### 3.3 怎么选

- 需要访问 `self`（实例属性）→ 实例方法。
- 需要访问/修改类属性 → 类方法。
- 与类无关的纯工具逻辑，只想归类管理 → 静态方法。

# 四、封装与属性控制

封装是「隐藏内部实现、对外暴露安全接口」。Python 没有真正的 private，靠**命名约定 + 名称改写**实现。

### 4.1 访问控制

```python
class User:
    def __init__(self, name, balance):
        self.name = name            # 公开属性
        self._nick = "内部"          # 单下划线：约定「受保护」，别直接访问
        self.__balance = balance    # 双下划线：名称改写，外部较难访问

    def get_balance(self):
        return self.__balance

u = User("张三", 1000)
print(u.get_balance())    # 1000，通过公开方法访问
print(u.__dict__)         # {'name': '张三', '_nick': '内部', '_User__balance': 1000}
```

- 单下划线 `_x`：约定「私有」，`from module import *` 时不会被导入，但外部仍能直接访问。
- 双下划线 `__x`：触发**名称改写（name mangling）**，实际变成 `_类名__x`，外部 `u.__balance` 会 AttributeError，但 `u._User__balance` 仍能访问到——所以也只是「防君子不防小人」，并非真正的私有。

### 4.2 property（把方法当属性）

`@property` 能把方法变成「属性」一样访问，同时能在读取/写入时做校验、计算（摘自练习代码 `chapter02/29.property.py`）：

```python
class Person:
    def __init__(self, age):
        self.__age = age

    @property                # 定义 getter
    def age(self):
        return self.__age

    @age.setter              # 定义 setter
    def age(self, value):
        if value < 0:
            raise ValueError("年龄不能为负")
        self.__age = value

p = Person(10)
print(p.age)      # 10，像属性一样读，无需加括号
p.age = 20        # 像属性一样赋值，触发 setter 校验
print(p.age)      # 20
```

property 的价值：

1. 对外接口简洁（`p.age` 而不是 `p.get_age()`）。
2. 内部可以加校验、计算、惰性加载等逻辑。
3. 从「公有属性」平滑改造成「带校验的属性」而不破坏调用方代码。

还可定义 `@age.deleter` 支持 `del p.age`。老的写法是 `age = property(get_age, set_age)`，新代码用装饰器更清晰。

# 五、魔法方法（dunder methods）

魔法方法是以双下划线开头结尾的特殊方法，由 Python 解释器在特定时机自动调用（如 `len()` 调 `__len__`、`str()` 调 `__str__`）。掌握它们才能写出「像内置类型一样好用」的自定义类。

### 5.1 常见魔法方法速查

| 魔法方法 | 触发时机 | 说明 |
| -------- | -------- | ---- |
| `__init__(self)` | `类()` 创建对象 | 初始化 |
| `__new__(cls)` | 创建对象前 | 控制对象创建（单例） |
| `__str__(self)` | `str(obj)` / `print(obj)` | 用户友好的字符串 |
| `__repr__(self)` | `repr(obj)` / 交互式直接输入 | 开发者友好的表示 |
| `__eq__(self, o)` | `==` | 相等判断 |
| `__lt__` / `__le__` / `__gt__` / `__ge__` | `<` `<=` `>` `>=` | 比较 |
| `__hash__(self)` | `hash(obj)`、作 dict 的 key | 哈希值 |
| `__len__(self)` | `len(obj)` | 长度 |
| `__getitem__` / `__setitem__` / `__delitem__` | `obj[k]` 读/写/删 | 索引/键访问 |
| `__iter__` / `__next__` | `for ... in obj` | 迭代 |
| `__call__(self)` | `obj()` | 让实例可调用 |
| `__enter__` / `__exit__` | `with obj` | 上下文管理 |
| `__contains__(self, item)` | `item in obj` | 成员判断 |

### 5.2 常用示例

```python
class Car:
    def __init__(self, color, brand, name, price):
        self.color, self.brand, self.name, self.price = color, brand, name, price

    def __str__(self):                       # print 时友好显示
        return f"{self.color} {self.brand} {self.name} {self.price}"

    def __repr__(self):                      # 开发者表示，尽量可还原
        return f"Car({self.color!r}, {self.brand!r}, {self.name!r}, {self.price!r})"

    def __eq__(self, other):                 # == 比较
        return (self.color, self.brand, self.name, self.price) == \
               (other.color, other.brand, other.name, other.price)

    def __lt__(self, other):                 # < 比较，按价格
        return self.price < other.price

c1 = Car("白色", "BYD", "汉", 180000)
c2 = Car("白色", "BYD", "汉", 180001)
print(c1)               # 白色 BYD 汉 180000（调用 __str__）
print(c1 == c2)         # False（调用 __eq__）
print(c1 < c2)          # True（调用 __lt__）
```

> 一个实用的注意点：**若重写了 `__eq__` 而不重写 `__hash__`，实例会变成不可哈希**（不能放进 set、不能作 dict 的 key）。需要同时支持相等比较和哈希时，二者要一起实现。

### 5.3 让对象支持 `[]` 和 `len()`

```python
class Scores:
    def __init__(self, data):
        self._data = data

    def __len__(self):
        return len(self._data)

    def __getitem__(self, index):          # 支持 s[0]、切片
        return self._data[index]

    def __contains__(self, item):          # 支持 in
        return item in self._data

s = Scores([90, 85, 78])
print(len(s))       # 3
print(s[0])         # 90
print(85 in s)      # True
```

# 六、继承与多态

### 6.1 单继承

子类继承父类的方法和属性，可以**重写（override）**父类方法：

```python
class Animal:
    def speak(self):
        print("动物叫")

class Dog(Animal):          # 继承 Animal
    def speak(self):        # 重写
        print("汪汪")

Dog().speak()               # 汪汪
```

### 6.2 super() 与多继承、MRO

Python 支持**多继承**。`super()` 按 **MRO（Method Resolution Order，方法解析顺序）** 依次查找父类；MRO 用 C3 线性化算法计算，可通过 `类.__mro__` 查看（摘自练习代码 `chapter02/21.面向对象高级.py`）：

```python
class Master:
    def __init__(self):
        self.kongfu = "[古法煎饼配方]"
    def make_cake(self):
        print(f"运用{self.kongfu}制作")

class School(object):
    def __init__(self):
        self.kongfu = "[AI煎饼配方]"
    def make_cake(self):
        print(f"运用{self.kongfu}制作")

class Prentice(Master, School):
    def make_master_cake(self):
        super().__init__()       # 按 MRO 找第一个有 __init__ 的父类
        super().make_cake()
    def make_school_cake(self):
        School.__init__(self)    # 直接指名父类，精确访问
        School.make_cake(self)

print(Prentice.__mro__)   # (Prentice, Master, School, object)
```

- `super()` 会**沿着 MRO 顺序**找，自动处理多继承协作。
- `父类名.方法(self)` 可精确指定调用哪个父类（不推荐常用，多继承时易混乱）。

> 多继承虽强大但容易造成「菱形继承」混乱。**能组合就不继承**，能用单继承就不多继承，是企业开发的经验法则。

### 6.3 多态与鸭子类型

Python 的多态依赖**鸭子类型**：「如果它走路像鸭子、叫声像鸭子，那它就是鸭子」——只关心对象有没有某个方法，不关心它是不是某个类的实例（摘自练习代码）：

```python
class Dog:
    def speak(self):
        print("汪汪")

class Cat:
    def speak(self):
        print("喵喵")

def make_sound(animal):      # 不限定 animal 类型
    animal.speak()           # 只要有 speak 方法就行

make_sound(Dog())   # 汪汪
make_sound(Cat())   # 喵喵
```

这与 Java 的「必须实现同一接口」不同，Python 更灵活，靠约定（都有 `speak` 方法）实现多态。

# 七、抽象类与抽象方法

抽象类定义「接口规范」，包含**抽象方法**（只有声明、没有实现），子类必须实现所有抽象方法才能实例化（摘自练习代码）：

```python
from abc import ABC, abstractmethod

class AC(ABC):                    # 抽象类
    @abstractmethod
    def cool_wind(self):          # 抽象方法
        pass

class XiaoMiAC(AC):
    def cool_wind(self):
        print("小米空调制冷")

xm = XiaoMiAC()                   # 实现了抽象方法，可实例化
# ac = AC()                       # TypeError，抽象类不能直接实例化
```

抽象类的价值：**强制约束子类实现约定方法**，定义清晰的接口契约（类似 Java 的接口/抽象类）。配合鸭子类型，抽象类用于「需要强制约束」的场景（如插件系统、多种数据源实现统一接口）。

# 八、进阶特性

### 8.1 `__slots__` 节省内存

默认每个实例用 `__dict__` 存属性（字典开销大）。用 `__slots__` 声明固定属性名，可以省内存、加速访问，同时**禁止动态添加属性**：

```python
class Point:
    __slots__ = ("x", "y")      # 只允许 x、y 两个属性
    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(1, 2)
# p.z = 3         # AttributeError，不能再动态加属性
# p.__dict__      # AttributeError，没有 __dict__ 了
```

适用场景：创建大量小对象的类（如坐标点、数据记录），能显著降低内存。

### 8.2 `__new__` 实现单例模式

单例保证一个类全程只有一个实例（如数据库连接池、配置对象）：

```python
class Singleton:
    _instance = None

    def __new__(cls, *args, **kwargs):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

a = Singleton()
b = Singleton()
print(a is b)      # True，同一个实例
```

### 8.3 dataclass 数据类

`@dataclass` 自动生成 `__init__`、`__repr__`、`__eq__` 等样板方法，专为「数据载体类」省代码（企业级常用）：

```python
from dataclasses import dataclass, field

@dataclass
class User:
    name: str
    age: int
    email: str = ""                     # 默认值
    tags: list = field(default_factory=list)   # 可变默认值必须用 default_factory

u1 = User("张三", 20)
u2 = User("张三", 20)
print(u1)              # User(name='张三', age=20, email='', tags=[])（自动 __repr__）
print(u1 == u2)        # True（自动 __eq__）
```

`dataclass` 是「类型注解 + 自动生成样板代码」的结合，广泛用于数据模型、DTO、配置类。注意可变默认值（如 list）要用 `field(default_factory=list)`，否则会踩和第 5 篇一样的可变默认参数陷阱。

### 8.4 类型注解 typing 进阶

第 5 篇讲了基础注解，这里补充配合 OOP 的进阶用法：

```python
from typing import Optional, Protocol, TypeVar, Generic

# 泛型：容器类型参数化
T = TypeVar("T")
class Box(Generic[T]):
    def __init__(self, item: T):
        self.item = item

box = Box[int](100)          # 明确 Box 装 int

# Protocol：结构化子类型（鸭子类型的静态版）
class Speaker(Protocol):
    def speak(self) -> None: ...

def greet(s: Speaker) -> None:
    s.speak()

# 任何有 speak 方法的对象都能传入，无需继承 Speaker
```

`Optional[X]` 等价 `X | None`（3.10+ 直接用后者），`Protocol` 用于「结构化类型」——只要求对象有某些方法，正是鸭子类型的静态化表达。

# 小结

面向对象是 Python 的进阶核心，重点掌握：

1. **`self` 与 `__init__`**：实例属性存 `__dict__`，`self` 是当前实例。
2. **类属性共享、实例属性独立**：查找顺序实例→类→父类。
3. **三类方法**：实例方法/类方法/静态方法的区别与选择。
4. **封装**：单/双下划线的约定与名称改写，`@property` 让方法像属性、可加校验。
5. **魔法方法**：`__str__/__repr__/__eq__/__lt__/__len__/__getitem__/__call__` 等，让自定义类「像内置类型」。
6. **继承与 MRO**：`super()` 沿 MRO 查找，多继承用 C3 线性化；多态靠鸭子类型。
7. **进阶**：`__slots__`、`__new__` 单例、`@dataclass`、`typing` 泛型与 Protocol。
