# 一、文件操作

### 1.1 打开文件 open()

```python
f = open("文件路径", "打开模式", encoding="utf-8")
```

| 模式 | 含义 |
| ---- | ---- |
| `r` | 只读（默认），文件必须存在 |
| `w` | 覆盖写，不存在会创建 |
| `a` | 追加写，不存在会创建 |
| `b` | 二进制模式（可与其他组合，如 `rb`、`wb`） |
| `+` | 读写模式（如 `r+`、`w+`） |

**务必显式指定 `encoding="utf-8"`**，否则依赖系统默认编码，Windows 上读中文易乱码。

### 1.2 读文件

```python
f = open("resources/望庐山瀑布.txt", "r", encoding="utf-8")

content = f.read()          # 读全部内容（返回字符串）
# content = f.read(10)      # 读指定长度
f.seek(0)                   # 重置文件指针到开头

line = f.readline()         # 读一行
f.seek(0)

lines = f.readlines()       # 读所有行，返回列表（每行一个元素）
f.close()
```

三个方法对比：

- `read()`：一次性全读，适合小文件。
- `readline()`：一次一行。
- `readlines()`：返回行列表。

**大文件不要用 read()**，会占满内存，应逐行遍历（见 1.4）。

### 1.3 写文件

```python
f = open("resources/静夜思.txt", "w", encoding="utf-8")
f.write("窗前明月光，\n")
f.write("疑是地上霜。\n")
f.close()
```

`write()` 不会自动加换行，需手动加 `\n`；`writelines(列表)` 可批量写一个字符串列表。

### 1.4 with 自动关闭 + 逐行遍历

用 `with` 打开文件，离开代码块自动关闭（即使异常也关闭），是**标准写法**：

```python
with open("file.txt", "r", encoding="utf-8") as f:
    for line in f:              # 直接遍历文件对象，逐行读取，不占内存
        print(line.strip())     # 去掉行尾换行符
```

文件对象本身可迭代，逐行遍历是处理大文件的最佳方式。

### 1.5 二进制文件

图片、音频等用 `rb` / `wb` 二进制模式：

```python
# 复制图片
with open("a.png", "rb") as src, open("b.png", "wb") as dst:
    dst.write(src.read())
```

# 二、路径与目录操作

### 2.1 os 与 os.path（传统方式）

```python
import os

print(os.getcwd())            # 当前工作目录
os.mkdir("dir")               # 创建目录（父目录须存在）
os.makedirs("a/b/c")          # 递归创建多级目录
print(os.listdir("."))        # 列出目录内容
os.chdir("dir")               # 切换目录
os.rmdir("dir")               # 删除空目录
os.remove("file.txt")         # 删除文件
os.rename("a", "b")           # 重命名

# os.path 路径处理
os.path.join("a", "b.txt")          # 拼接路径（跨平台，推荐用它而非手动拼 "/"）
os.path.exists("a.txt")             # 是否存在
os.path.isfile("a.txt")             # 是否文件
os.path.isdir("a")                  # 是否目录
os.path.abspath("a.txt")            # 绝对路径
os.path.basename("/a/b.txt")        # 文件名 b.txt
os.path.dirname("/a/b.txt")         # 目录 /a
os.path.splitext("b.txt")           # ('b', '.txt')，拆分扩展名
```

### 2.2 pathlib（现代推荐，3.4+）

`pathlib` 用面向对象的 `Path` 统一处理路径，比 `os.path` 更简洁、可读性更好，**新代码优先用 pathlib**：

```python
from pathlib import Path

p = Path("resources") / "data" / "file.txt"   # 用 / 拼接路径
print(p.exists())                 # 是否存在
print(p.is_file())                # 是否文件
print(p.name)                     # file.txt
print(p.stem)                     # file（无扩展名）
print(p.suffix)                   # .txt
print(p.parent)                   # 父目录
print(p.read_text(encoding="utf-8"))    # 直接读文本
p.write_text("hello", encoding="utf-8")  # 直接写文本

# 遍历目录下所有 .py 文件
for f in Path(".").glob("*.py"):
    print(f)

# 递归遍历
for f in Path(".").rglob("*.txt"):
    print(f)
```

`Path.glob()` 匹配文件、`rglob()` 递归匹配，比手动遍历目录简洁得多。

### 2.3 shutil 高级文件操作

`shutil` 提供复制、移动、删除目录等高层操作：

```python
import shutil

shutil.copy("a.txt", "b.txt")          # 复制文件
shutil.copy2("a.txt", "b.txt")         # 复制并保留元数据
shutil.move("a.txt", "dir/")           # 移动文件
shutil.rmtree("dir")                   # 递归删除整个目录（危险，慎用）
shutil.copyfileobj(src, dst)           # 大文件复制（分块读）
```

# 三、JSON 序列化

JSON 是互联网数据交换的事实标准，Python 通过 `json` 模块与 `dict`/`list` 互转（摘自练习代码 `chapter02/24.json.py`）。

### 3.1 序列化与反序列化

```python
import json

data = {"name": "Tom", "age": 20, "skills": ["Python", "Java"]}

# 序列化：Python 对象 → JSON 字符串
json_str = json.dumps(data)
print(json_str)                 # {"name": "Tom", "age": 20, ...}

# 反序列化：JSON 字符串 → Python 对象
obj = json.loads(json_str)
print(type(obj))                # <class 'dict'>
```

记忆口诀：**`s` 结尾的是字符串（dumps/loads），不带 s 的是文件（dump/load）**。

| 函数 | 作用 |
| ---- | ---- |
| `dumps(obj)` | 对象 → JSON 字符串 |
| `loads(str)` | JSON 字符串 → 对象 |
| `dump(obj, f)` | 对象 → 写入文件 |
| `load(f)` | 从文件读取 → 对象 |

### 3.2 写入 / 读取文件

```python
user = {"name": "张三", "age": 18, "hobbies": ["reading", "swimming"]}

# 写入文件：ensure_ascii=False 保留中文，indent 格式化缩进
with open("user.json", "w", encoding="utf-8") as f:
    json.dump(user, f, ensure_ascii=False, indent=2)

# 读取文件
with open("user.json", "r", encoding="utf-8") as f:
    user = json.load(f)
    print(user)
```

常用参数：

- `ensure_ascii=False`：中文不被转成 `\uXXXX`，保持可读（**写中文 JSON 必加**）。
- `indent=2`：格式化缩进，便于阅读。
- `sort_keys=True`：按键排序输出。

### 3.3 自定义对象序列化（default）

`json.dumps` 只能序列化 dict/list/str/int 等基本类型，自定义类对象需要指定 `default`：

```python
import json
from dataclasses import dataclass

@dataclass
class User:
    name: str
    age: int

def to_dict(obj):
    if isinstance(obj, User):
        return {"name": obj.name, "age": obj.age}
    raise TypeError(f"无法序列化 {type(obj)}")

u = User("张三", 20)
print(json.dumps(u, default=to_dict))        # 用 default 处理
print(json.dumps(u, default=lambda o: o.__dict__))  # 简化写法（取 __dict__）
```

### 3.4 自定义反序列化（object_hook）

读取时想把 dict 还原成自定义对象，用 `object_hook`：

```python
def to_user(d):
    if "name" in d and "age" in d:
        return User(**d)
    return d

u = json.loads('{"name": "张三", "age": 20}', object_hook=to_user)
print(u)     # User(name='张三', age=20)
```

# 四、CSV 处理

CSV（逗号分隔值）是表格数据的通用格式，`csv` 模块处理。

### 4.1 读写基础

```python
import csv

# 写
with open("data.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["姓名", "年龄", "城市"])       # 写表头
    writer.writerows([["张三", 20, "北京"], ["李四", 22, "上海"]])  # 写多行

# 读
with open("data.csv", "r", encoding="utf-8") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)          # 每行是一个列表
```

> 写 CSV 时 `open` 加 `newline=""`，否则 Windows 下会多出空行。

### 4.2 DictReader / DictWriter（按列名访问）

用字典形式读写，字段名做 key，更适合有表头的表格：

```python
import csv

# 写
with open("data.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=["姓名", "年龄"])
    writer.writeheader()                          # 写表头
    writer.writerow({"姓名": "张三", "年龄": 20})

# 读
with open("data.csv", "r", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row["姓名"], row["年龄"])   # 按列名取值
```

# 五、正则表达式

正则用于字符串的模式匹配，是数据清洗、日志解析、表单校验的核心工具。Python 用 `re` 模块。

### 5.1 核心函数

| 函数 | 作用 |
| ---- | ---- |
| `re.match(pattern, s)` | 从**开头**匹配，返回第一个 match 对象 |
| `re.search(pattern, s)` | 在**任意位置**匹配，返回第一个 match 对象 |
| `re.findall(pattern, s)` | 返回**所有**匹配结果的列表 |
| `re.finditer(pattern, s)` | 返回所有匹配的迭代器（含位置信息） |
| `re.sub(pattern, repl, s)` | 替换匹配的内容 |
| `re.split(pattern, s)` | 按匹配切分 |
| `re.compile(pattern)` | 预编译正则（复用提高性能） |

```python
import re

s = "我的手机号是18809090000，另一个是18800008888"

# match：从开头匹配（s 开头不是手机号，返回 None）
print(re.match(r"1[3-9]\d{9}", s))          # None
# search：任意位置匹配
print(re.search(r"1[3-9]\d{9}", s).group()) # 18809090000
# findall：全部匹配
print(re.findall(r"1[3-9]\d{9}", s))        # ['18809090000', '18800008888']
```

> `match` 与 `search` 的区别是高频考点：`match` 只在字符串开头匹配，`search` 扫全串。

### 5.2 常用元字符与量词

| 语法 | 含义 |
| ---- | ---- |
| `.` | 任意字符（除换行） |
| `\d` | 数字 |
| `\w` | 字母/数字/下划线 |
| `\s` | 空白字符 |
| `\D \W \S` | 对应的「非」 |
| `[abc]` | 字符集，匹配 a/b/c 之一 |
| `[^abc]` | 不在字符集内 |
| `[3-9]` | 范围，3 到 9 |
| `^` / `$` | 字符串开头 / 结尾 |
| `\b` | 单词边界 |

量词（限定前面元素出现次数）：

| 量词 | 含义 |
| ---- | ---- |
| `*` | 0 次或多次 |
| `+` | 1 次或多次 |
| `?` | 0 次或 1 次 |
| `{n}` | 恰好 n 次 |
| `{n,}` | 至少 n 次 |
| `{n,m}` | n 到 m 次 |

```python
print(re.findall(r"\d+", "我有 12 个苹果和 345 个梨"))   # ['12', '345']
print(re.fullmatch(r"1[3-9]\d{9}", "13812345678"))       # 完整匹配手机号
```

### 5.3 分组与命名分组

`()` 定义分组，可提取匹配中的子串：

```python
m = re.search(r"(\d{4})-(\d{2})-(\d{2})", "日期 2026-03-27")
print(m.group(0))    # 2026-03-27，整体匹配
print(m.group(1))    # 2026
print(m.group(2))    # 03
print(m.groups())    # ('2026', '03', '27')

# 命名分组（更可读）
m = re.search(r"(?P<year>\d{4})-(?P<month>\d{2})-(?P<day>\d{2})", "2026-03-27")
print(m.group("year"))     # 2026
print(m.groupdict())       # {'year': '2026', 'month': '03', 'day': '27'}
```

### 5.4 贪婪 vs 非贪婪

默认**贪婪匹配**（尽量多匹配），加 `?` 变**非贪婪**（尽量少匹配）：

```python
s = "<a>内容1</a><b>内容2</b>"
print(re.findall(r"<.*>", s))     # ['<a>内容1</a><b>内容2</b>']  贪婪，匹配到最后一个 >
print(re.findall(r"<.*?>", s))    # ['<a>', '</a>', '<b>', '</b>'] 非贪婪
```

### 5.5 替换与切分

```python
s = "电话: 13812345678, 备注: 无"
print(re.sub(r"1[3-9]\d{9}", "***", s))   # 电话: ***, 备注: 无

print(re.split(r"[,，]", "a,b，c"))        # ['a', 'b', 'c']，按逗号切分
```

### 5.6 预编译与标志

频繁使用同一个正则时，`compile` 预编译可提高性能：

```python
pattern = re.compile(r"1[3-9]\d{9}")
print(pattern.findall("13812345678 and 13900001111"))
```

常用标志（flags）：`re.I`（忽略大小写）、`re.S`（`.` 匹配换行）、`re.M`（多行模式）。

```python
print(re.findall(r"python", "Python PYTHON", re.I))   # ['Python', 'PYTHON']
```

> 正则里写 `\` 会与字符串转义冲突，所以**正则一律用原始字符串 `r"..."`**（第 3 篇讲过）。

# 六、日期时间

`datetime` 是处理日期时间的标准模块，核心类（摘自练习代码 `chapter02/27.日期时间.py`）：

| 类 | 含义 |
| ---- | ---- |
| `date` | 日期（年-月-日） |
| `time` | 时间（时:分:秒） |
| `datetime` | 日期 + 时间（最常用） |
| `timedelta` | 时间差 |

### 6.1 获取与创建

```python
from datetime import datetime

now = datetime.now()                    # 当前日期时间
print(now)                              # 2026-03-27 10:30:00.123456

dt = datetime(2026, 3, 27, 10, 30, 0)   # 创建指定日期时间
print(dt.year, dt.month, dt.day)        # 2026 3 27
print(dt.hour, dt.minute, dt.second)    # 10 30 0
```

### 6.2 格式化 strftime / strptime

```python
# 时间 → 字符串（格式化输出）
s = now.strftime("%Y-%m-%d %H:%M:%S")
print(s)                     # 2026-03-27 10:30:00

# 字符串 → 时间（解析）
dt = datetime.strptime("2026-03-27 10:30:00", "%Y-%m-%d %H:%M:%S")
print(dt)
```

常用格式符：`%Y`（四位年）、`%m`（月）、`%d`（日）、`%H`（时）、`%M`（分）、`%S`（秒）、`%A`（星期全称）。

### 6.3 时间运算 timedelta

```python
from datetime import datetime, timedelta

now = datetime.now()
print(now + timedelta(days=1))     # 加 1 天
print(now - timedelta(hours=2))    # 减 2 小时

t1 = datetime(2026, 3, 27)
t2 = datetime(2026, 3, 20)
delta = t1 - t2
print(delta.days)                  # 7，两日期相差天数
print(delta.total_seconds())       # 相差总秒数
```

### 6.4 时间戳

```python
# 时间 → 时间戳（秒）
ts = now.timestamp()
print(ts)

# 时间戳 → 时间
dt = datetime.fromtimestamp(ts)
print(dt)
```

时间戳是「自 1970-01-01 00:00:00 UTC 起的秒数」，常用于日志记录、跨系统传递时间。

### 6.5 time 模块（补充）

`time` 模块提供更底层的时间函数：

```python
import time
time.time()          # 当前时间戳（秒）
time.sleep(2)        # 暂停 2 秒
time.time_ns()       # 纳秒时间戳（精确计时）
```

# 小结

本篇是「数据处理」的四件套，企业开发中几乎天天用到：

1. **文件操作**：`open` 模式、`with` 自动关闭、逐行遍历大文件、`encoding="utf-8"`。
2. **路径**：`pathlib.Path`（现代首选）、`os/os.path`、`shutil`。
3. **JSON/CSV**：`dumps/loads`（字符串）vs `dump/load`（文件）、`ensure_ascii=False`、`default`/`object_hook` 处理自定义对象、`DictReader/DictWriter`。
4. **正则**：`match` vs `search` vs `findall`、元字符与量词、分组、贪婪/非贪婪、原始字符串 `r"..."`。
5. **日期时间**：`datetime`/`timedelta`、`strftime/strptime`、时间戳。
